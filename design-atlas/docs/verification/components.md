## Границы проверки

Next fixture проверяет production сборку, выполнение и строгие типы примеров подключения с включённой проверкой TypeScript. Комплект использует пакетный JS runtime с декларациями типов; оригинальные TSX/TS файлы сохранены отдельно. Внутренние ошибки вывода типов upstream не исправляются редактированием исходников. Сам Atlas также проходит строгую проверку TypeScript. Исходники библиотек не являются сертификатом доступности; индивидуальные особенности указаны в панели компонента. GPU нагрузка зависит от устройства.

Повторение: npm test; npm run build; npm run test:next. Preview и ZIP заново создаются из локальных файлов через npm run components:build. Сеть для этого не нужна.
