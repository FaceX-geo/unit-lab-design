# Проверка Design Atlas

Проверено 3 октября 2026 года.

## Автоматически

`npm test` прошёл: 250 модулей, 19 категорий, 42 источника; уникальные и стабильные ID; заполненные объяснения, ограничения и примеры; минимум два правила на модуль; ссылки на существующие категории и источники. Скрипт обновил `public/catalog.csv` и `public/catalog.json`.

Валидация импорта проверена на неверной версии и структуре, неизвестных и повторяющихся ID, слишком длинной заметке, недопустимых индексах чек-листа, неверных настройках и корректном круговом преобразовании. Личные данные настоящего браузера этими автоматическими проверками не затрагивались.

`npm run build` прошёл: TypeScript и production-сборка Vite. Локальный адрес отвечает HTTP 200. Синтаксис macOS-файла запуска проверен через `zsh -n`.

## В браузере

- Поиск «золотое сечение» возвращает нужный модуль.
- Закладка, заметка и отметка правила сохраняются после перезагрузки страницы.
- Горизонтальное положение меняется ползунком; клавиатура меняет значение.
- Калькулятор показал 21,00:1 для чёрного и белого и 1,00:1 для одинакового белого. Проверка порогов использует неокруглённое значение. HEX-поля проверены через реальный интерфейс.
- У пружинного примера изменена длительность на 1200 ms, запуск переводит кнопку в «Повторить».
- Сравнение ограничено тремя модулями; экран содержит правила и ограничения. Кнопка из нижней панели отдельно проверена на двух модулях.
- Валидный тестовый JSON импортирован через file chooser: повторная закладка не дублируется, неизвестный ID отброшен, заметка и чек-лист восстановлены.
- JSON-экспорт вызывает подтверждение в интерфейсе. Встроенный браузер не предоставил событие download, поэтому фактическое сохранение скачанного файла в нём не подтверждено. Генерация и структура данных проверены; статические CSV/JSON сохранены в проекте. Для скачивания резервной копии можно использовать обычный браузер с тем же локальным адресом.
- iOS-модель переключена в Android, настройка уведомлений выключена, тёмная тема применена визуально.
- Проверены компоновки при 390 × 844 и 1440 × 1000. Скриншоты сохранены в `docs/screenshots`.
- Скрытая мобильная панель исключена из клавиатурного фокуса через inert. При открытии фокус переходит в меню; Escape закрывает меню и возвращает фокус.
- Временные закладки, заметки и отметки, созданные для проверки, очищены. Начальный личный отбор пуст.

## Границы проверки

Это не полный аудит WCAG, не тест всех комбинаций ОС и браузеров и не сравнение с настоящими нативными SDK. Некоторые модули используют общую лабораторную сцену; их отдельные аспекты объяснены правилами и сценарием. Отключение сети проверено структурно: runtime-ресурсы и шрифты локальные, внешние ссылки используются только для чтения источников.
