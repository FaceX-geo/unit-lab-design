# Design Atlas

Личный локальный каталог: **91 оригинальный интерактивный компонент и 250 модулей в 19 разделах**, 42 ссылки на первичные и официальные источники. Русский интерфейс; пояснения, правила, ограничения и сценарий у каждого модуля.

## Запуск

На macOS дважды нажмите **Открыть Design Atlas.command**. Он откроет http://127.0.0.1:5173/ и оставит сервер работать в терминале. Node.js уже установлен на этом компьютере.

Из терминала в папке проекта:

```sh
npm ci       # только первая установка / восстановление зависимостей
npm run dev
```

Откройте http://127.0.0.1:5173/. Остановить сервер: Ctrl+C в его терминале. Он слушает только loopback 127.0.0.1.

Для готовой сборки: `npm run build`, затем `npm run preview -- --port 5173`. Используйте тот же адрес и порт, чтобы видеть прежний локальный отбор.

После установки зависимостей приложение работает без интернета. Шрифты, иконки и примеры локальные. Внешние источники требуют сети. Сервер должен быть запущен: это локальная веб-модель, а не установленное нативное приложение и не service-worker PWA.

## Что можно делать

- Искать по названию, описанию, правилам и сценариям; ограничивать категорию и тип; менять сортировку и вид.
- Добавлять закладки, писать заметки, отмечать выбранные правила и сравнивать до трёх модулей.
- Пробовать композицию, группировку, типографику, палитры, контраст, сетки, компоненты, состояния и движение.
- В лаборатории менять цвет, радиус, интервалы, длительность, платформу и уменьшение движения; экспортировать CSS-токены.
- Сравнивать учебные HTML/CSS-модели Web, iOS, Android и Desktop. Системные API, haptics и жесты настоящих SDK не имитируются.
- Экспортировать отбор с заметками и настройками в JSON или Markdown. Импорт JSON объединяет закладки; одноимённые заметки и настройки обновляются из файла.
- Получить весь каталог: [CSV](public/catalog.csv) или [JSON](public/catalog.json), либо кнопкой на странице «Источники и метод».

`⌘K` / `Ctrl+K` — поиск. `Escape` — закрыть модуль. Нативные поля и ползунки работают с клавиатуры.

## Коллекция компонентов

Откройте http://127.0.0.1:5173/#components или «Компоненты» в меню. Коллекция включает 26 React Bits, 15 Kokonut UI, 12 Magic UI, 10 Animate UI, 6 Paper Shaders, 5 HTML/CSS элементов Uiverse, по 4 SmoothUI и Fancy Components, по 3 Motion Primitives, Cult UI и Animata. Справочник содержит 12 библиотек, включая Aceternity UI со ссылкой на оригинальный каталог и условия использования.

Подборка «Новое» выделяет 41 добавленный модуль; «Ещё 20 эффектов» — отдельные 20 эффектов, среди которых 12 WebGL фонов. В Kokonut UI включены все 11 позиций со скриншотов: Morphic Navbar, Toolbar, Smooth Tab, Profile Dropdown, Action Search Bar, Scroll Text, Typing Text, Matrix Text, Dynamic Text, Glitch Text и Shimmer Text. Дополнительно доступны Particle Button, Liquid Glass, Card Stack и File Upload. Полный список расширения — в [отчёте проверки](docs/verification/expansion.md).

Карточки используют статические локальные превью. Исходные реализации выполняются в отдельных sandbox iframe; WebGL и уменьшение движения требуют ручного запуска. Остановка, смена вкладки и закрытие выгружают iframe. Доступны параметры, поиск, категории, фильтры, избранное, заметки и фон/размер демо.

В панели есть оригинальный код, пример подключения, точная команда установки зависимостей и ZIP. Комплект включает оригинальные транзитивные исходники, скомпилированный JS runtime с декларациями типов, CSS, aliases, React/Next примеры, лицензии и manifest.json с SHA-256. Демо-контент создан для Atlas; исходные файлы библиотек сохранены без изменений. Runtime переводит статический require в ESM import, а CSS с @apply — в обычный CSS. Card Stack использует локальные CC0 SVG вместо четырёх стандартных внешних изображений; оригинальный исходник сохраняет авторские URL. React/Vite получает адаптеры next/link и next/image к HTML; Next.js использует свои компоненты. Paper Shaders сохраняет Apache-2.0 и NOTICE, остальные новые библиотеки — MIT.

NextExample.tsx — клиентская граница с dynamic(..., {ssr:false}), которая изолирует браузерные API. Сохраните структуру файлов, объедините aliases из tsconfig.paths.json и подключите необходимые стили. Для Vite добавьте componentAliases из vite.config.fragment.mjs в resolve.alias. demo.css — стили изолированного примера; при интеграции в существующее приложение переносите нужные классы и токены с учётом его темы. Автоматическая адаптация и передача в Codex остаются следующим этапом. Сейчас копируется компактный паспорт с ID, ревизией, хешем и ссылкой на manifest.

Сборки демо и ZIP не хранятся в Git; статические JPEG карточек сохранены. npm run dev / build автоматически создают демо и архивы локально, затем используют кеш. Первый запуск может занять несколько минут. Ручные команды:

```sh
npm run components:build  # пересобрать локальные примеры и архивы
npm run components:import # повторно получить закреплённые исходники из официальных репозиториев
npm run components:import -- --only-new # импортировать только ещё не добавленные позиции
npm run test:react        # собрать 86 экспортируемых примеров в React/Vite
npm run test:next         # собрать fixture с 86 App Router маршрутами
```

Обновление исходников выполняется вручную: измените нужную ревизию в components.lock.json, запустите импорт и сборку, переснимите превью и повторите проверки. При повторном импорте закреплённые ревизии сохраняются. Лицензии каждого автора включены в комплекты. React Bits использует MIT + Commons Clause с дополнительными ограничениями; эта коллекция предназначена для личного локального использования.

Сводка текущих проверок: [расширение коллекции](docs/verification/expansion.md). Проверка первоначальных 50 компонентов сохранена в [историческом отчёте](docs/verification/components.md). Fixture Next проверяет сборку и строгие типы примеров подключения; проверка TypeScript включена. Fixture React проверяет экспорт в Vite с зависимостями и адаптерами. Все 86 примеров обеих сборок открыты в браузере. Оригинальные TSX/TS сохранены без исправлений; для подключения используется JavaScript с декларациями типов, как в обычном пакете. Atlas проверяется TypeScript отдельно.

## Хранение

Экспорт имеет версию 2; импорт версии 1 поддерживается. Избранное, заметки и параметры компонентов хранятся вместе с прежними данными. Ключ сохранён: `design-atlas:v1` в localStorage. Данные привязаны к браузеру, протоколу, адресу и порту. `localhost` и `127.0.0.1`, а также порты 5173 и 4173 имеют разные хранилища. Очистка данных браузера может удалить отбор. Для переноса и резервной копии используйте JSON-экспорт. Приложение не отправляет личный отбор во внешние сервисы. При скачивании JSON/Markdown содержимое передаётся серверу на 127.0.0.1, который возвращает файл без сохранения на серверном диске. Этот обработчик работает в Vite dev и preview.

## Метод

Конечного общепринятого списка «всех правил дизайна» не существует. Эта библиотека — расширяемая карта ориентиров. Пять типов материалов: стандарт, эвристика, художественный приём, визуальное направление и рабочая практика.

Тексты и схемы написаны для каталога. Источники указывают на нормативную опору или дополнительное чтение, а не означают, что источник предписывает каждый авторский совет. Перенос правил фотографии, кино и классической анимации в UI — интерпретация. Золотое сечение не гарантирует красоты или удобства.

Демонстрации сгруппированы по семействам: некоторые модули используют общую лабораторную сцену. Интерактивные схемы иллюстрируют выбранные параметры; прочие аспекты раскрыты в правилах и сценариях. Пружина — приближение ключевыми кадрами, не физический движок; FLIP и scroll-linked показывают характер результата, а не полный алгоритм. Вся библиотека не является сертифицированным аудитом соответствия WCAG.

## Расширение и проверка

- `src/catalog.ts` — категории и материалы; ID стабильны, новые материалы добавляйте в конец раздела.
- `src/demos.tsx` — интерактивные семейства и миниатюры.
- `src/sources.ts` — источники и пояснения.
- `src/storage.ts` — валидация импорта и хранение.
- `src/App.tsx`, `src/styles.css` — интерфейс.

`npm test` проверяет целостность каталога и импорт, затем обновляет статические CSV/JSON. `npm run build` проверяет TypeScript и собирает приложение. Итоги ручной проверки браузера находятся в `docs/verification.md`.

Шрифты Manrope и Unbounded распространяются по SIL Open Font License; лицензии сохранены в `public/fonts`. SVG-иконки: Lucide (ISC). Примеры и схемы сделаны кодом, без внешней фотографии и видеоресурсов.
