# Unit Lab Design

Личная локальная библиотека дизайна — Design Atlas: **91 интерактивный компонент из 11 библиотек и 250 модулей о правилах и практиках дизайна**.

Живые демо, анимированные фоны, поиск, избранное, заметки, копирование исходников и ZIP-комплекты для React и Next.js. Реализации сторонних компонентов закреплены по ревизиям; лицензии и контрольные суммы включены в комплекты.

## Запуск

```sh
cd design-atlas
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173/. Первый запуск создаёт локальные сборки демо и архивы и может занять несколько минут. После установки зависимостей коллекция работает локально без интернета.
